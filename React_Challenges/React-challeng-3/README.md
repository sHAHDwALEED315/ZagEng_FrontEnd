# React Dynamic Product Cards

A simple React application that displays product cards dynamically using React components and props.

## Features

* Display product image, title, category, and price.
* Render multiple products using `map()`.
* Pass data between components using `props`.
* Use inline styling for card design.

## Technologies Used

* React
* Vite
* JavaScript (ES6)
* JSX

## Project Structure

```text
src/
├── App.jsx
├── Card.jsx
├── ProductCards.jsx
└── data.js
```

## Run the Project

```bash
npm install
npm run dev
```
